CNN LAYER:
Given an image (matrix of pixels)
- Filters (PATTERN TO LOOK FOR, SIZE SUBSET OF IMAGE SIZE)
    - Apply filters for pattern recognition
    - Do this by sliding the filters across the image
        - FOR EACH POSSIBLE LOCATION OF FILTER e.g. 3X3 PIXELS:
            - MATDOTPRODUCT FILTER X BLOCK = NUMBER
            - STRIDE IS NUMBER OF ELEMENTS YOU SHIFT
            - WILL END UP WITH FEATURE MAP
    - Location invariant
    - Multiple layers of filters
        - More abstract patterns etc.
        - Aggregate using different filter (3D filter)
    - FLATTEN your last set of features into one vector, input to NN
- POOLING
    - DOWNSCALE IMAGE
        - e.g. 2x2 filter with stride=2, take max number in the filter
    - Reduce computation
    - Reduce overfitting (less parameters)
    - Noise filtering
- PADDING
    - Adds 1 row/column of zeros
    - Then a 3x3 kernel slides over and outputs 28x28, preserving original size 
    - padding = floor(kernel_size / 2)

- FILTERS ARE LEARNED PARAMETERS
    - HOW MANY FILTERS, AND SIZE

Rotation/Scaling
- Not handled by CNN
- Either
    - Have rotated/scaled samples in training data OR
    - Use DATA AUGMENTATION to generate rotated/scaled from existing training samples

Why CNN works better for vision than MLP?
    - Fully connected NN would destroy spatial information
    - Many parameters 

BUT ITS BASICALLY THE SAME THING, MAXIMIZING THE AMOUNT THE FILTERS DESCRIBE FEATURES IN THE IMAGE
